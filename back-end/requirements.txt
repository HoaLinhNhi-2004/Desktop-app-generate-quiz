# Direct dependencies, pinned.
#
# Every version here is exact on purpose. This file feeds the PyInstaller
# bundle, and an unpinned upstream release is enough to break a build that
# changed no code of ours: releases v1.5.0 through v1.7.0 shipped without a
# working `tzdata` and the backend died on every machine before it bound a port.
# `--selfcheck` catches a missing module; only pinning stops the version drift
# that introduces one.
#
# Requires Python 3.12–3.14: numpy 2.5 dropped 3.11, and youtube-transcript-api
# caps at <3.15. CI and both build scripts pin 3.12 to match.
#
# Captured from the working venv on Python 3.12. Transitive dependencies are
# deliberately left out so the "why" comments below stay readable — see
# docs/backend-architecture.md for the upgrade procedure.
#
# To upgrade one package: bump it here, reinstall, then run
#   python app.py --selfcheck  &&  python smoke_test_bundle.py <exe>
